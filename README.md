# Holodori Optimizer

A fan-made team optimizer for **Hololive Dreams**.

Holodori Optimizer helps you compare teams, songs, Holomem Board setups, and score potential without having to manually test every combination in-game.

> **Current version:** 3.14.0-beta.15  
> **Exact chart data:** r51

## ✨ What can it do?

- 🧮 **Optimize your team** for the highest projected score
- 🎵 Compare teams across individual songs or search across all available songs
- 📊 Use exact chart timing for more accurate score calculations
- 🧩 Include your **Holomem Board** bonuses in optimization
- 📷 Import your roster using the built-in card image recognizer
- 🇬🇧 🇯🇵 Switch between English and Japanese
- 💾 Run entirely in your browser — no installation required

## 🚀 How to use it

### Online

Open the optimizer through the GitHub Pages link for this repository.

### Offline

1. Download this repository or the latest release.
2. Open `index.html` in a modern browser.
3. That's it!

Everything needed by the optimizer is bundled locally, so an internet connection is not required once you have the file.

## 🎮 Included game content

This public build currently contains:

- **167 cards**
- **177 songs**
- **702 exact chart timelines**
- **405,194 packed note events**
- Local artwork for all included cards
- Local jackets for all included songs
- Card-recognition references for all 167 cards

Game content is updated as new publicly announced content becomes available.

## 📷 Roster Import

If you don't want to enter your cards manually, the optimizer includes a browser-based image recognizer.

Upload screenshots of your Hololive Dreams roster and the optimizer will attempt to identify the cards for you. You can review and correct the detected results before using them.

No screenshots are uploaded to a server — recognition runs locally in your browser.

## 🧩 Holomem Board

Holodori Optimizer supports Holomem Board bonuses and can account for them when evaluating teams.

You can enter your current Board setup or use the Board optimization tools to compare possible improvements.

## ⚠️ Beta notice
