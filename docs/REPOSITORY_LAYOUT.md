# Repository layout

- `src/` contains the editable browser/scoring/recognizer sources.
- `dist/` contains only the current distributable HTML and its bundled chart-data companion.
- `validation/` contains machine-readable and release-specific QC records.
- `docs/` contains architecture, validation summaries, and performance notes.
- `tools/` contains optional developer utilities.

Historical distributable HTML builds are intentionally not kept in the repository; use Git history or GitHub Releases for prior versions.
